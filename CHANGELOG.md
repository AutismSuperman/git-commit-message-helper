# Changelog

## [Unreleased]

## [1.6.5] - 2026-10-05

- Add the OpenAI Responses API as a third provider protocol alongside Chat Completions and Anthropic Messages.
- Replace the reasoning compatibility checkbox with per-profile thinking level drop-downs: model default, off, low, medium, high, and max.
- Map thinking levels to the parameter each API format supports, covering OpenAI reasoning models, Anthropic thinking budgets, Responses reasoning effort, and vendor switches for Qwen, Zhipu, Moonshot, Doubao, MiMo, DeepSeek, OpenRouter, and MiniMax.
- Show the resolved request path next to the API format selector and add a thinking column to the model list.
- Migrate existing reasoning compatibility settings to the disabled thinking level and remember when a provider rejects thinking parameters.
- Fix an EDT access violation when LLM actions read the commit panel selection from a background thread.
- Require IntelliJ Platform 2024.1 or newer: the commit panel action buttons rely on the Vcs.MessageActionGroup toolbar group introduced in that release.

## [1.6.4] - 2026-07-05

- Add an LLM generate action that accepts extra user context, such as closed issues, bug IDs, and skip-CI instructions.
- Add an independent visibility setting for the extra-context generate action.
- Hide the LLM format action by default while keeping manual, LLM generate, and extra-context generate actions visible.
- Add a dedicated SVG icon for the extra-context generate action.
- Add reusable prompt profiles with create, rename, edit, and delete support.
- Add global and project default prompt selection, with project prompts taking precedence.
- Apply the selected prompt to LLM commit generation and formatting while preserving required output constraints.

## [1.6.3] - 2026-06-22

- Add support for multiple commit templates with a protected Default template.
- Add global and project default template selection.
- Improve the commit template settings layout, preview area, description scrolling, and native Settings UI spacing.
- Apply the selected project or global template when rendering generated and formatted commit messages.

## [1.6.2] - 2026-06-20

- Optimize the commit template settings layout with a resizable editor and preview split view.
- Improve template editor soft wrapping and make template variable documentation more compact and readable.
- Support LLM commit message generation and formatting from Git Log edit commit message dialogs.
- Add in-place stop controls for LLM generate, format, and Smart Echo operations.

## [1.6.1] - 2026-06-20

- Fix malformed or truncated LLM JSON responses from interrupting commit generation.
- Increase LLM response token budget for long diffs and reasoning model outputs.
- Add safer fallback parsing so incomplete responses do not produce vague commit messages.

## [1.6.0] - 2026-06-20

- Add one-click reasoning model compatibility for OpenAI-compatible and Anthropic-compatible providers.
- Add request diagnostics, compatibility fallback caching, and streaming fallback for unstable model gateways.
- Improve LLM commit generation by rendering structured template fields locally and formatting detailed body entries as bullets.
- Improve large diff summarization and generated commit message quality checks.

## [1.5.5] - 2026-06-20

## [1.5.4] - 2026-06-20
