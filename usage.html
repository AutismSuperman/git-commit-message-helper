Usage guide

安装、配置与日常使用

这份引导覆盖插件安装、提交面板动作、模板配置、提交类型维护、LLM Provider 配置和 Smart Echo 使用方式。

安装 提交工作流 配置入口 LLM 设置 截图说明
01

安装插件

在 JetBrains IDE 中进入插件市场安装：

  1. 打开 File → Settings → Plugins。
  2. 进入 Marketplace，搜索 Git Commit Message Helper。
  3. 点击安装并按 IDE 提示重启。
打开 JetBrains Marketplace
02

提交面板工作流

插件会在 VCS Commit Message 区域中加入四个动作。它们可以在设置页里单独控制显示或隐藏。

动作 用途
Generate Commit Message 根据当前选中的变更生成提交信息。
Generate Commit Message With Additional Context 先输入本次生成的附加要求（关闭的 issue、跳过 CI、Bug 说明等），再生成提交信息。
Format Commit Message 把已有提交草稿重写为符合模板的格式。
Create Commit Message 打开结构化编辑窗口，手动填写字段并生成最终提交信息。
03

配置入口

设置入口为 File → Settings → Git Commit Message Helper。

通用设置

调整类型展示模式、内联展示数量、隐藏字段、Skip CI 默认值和四个提交动作的显示状态。

提交模板

模板由 Apache Velocity 驱动，支持多模板档案与全局/项目默认，可以完全控制最终提交信息的渲染格式。

提交类型

维护团队允许使用的提交类型和描述，例如 feat、fix、docs、style、refactor、test、chore。

提示词

创建可复用的提示词档案，并为全局与当前项目分别指定默认值，控制 LLM 生成与格式化的行为。

type(scope): subject

body

BREAKING CHANGE: changes

Closes issue

[skip ci]
04

LLM Provider 设置

在 LLM 设置页配置默认模型、接口协议、Base URL、API Key、Model、Temperature、回复语言、最大差异长度和思考等级。每个模型档案可以使用不同的接口协议和思考等级。

OpenAI Compatible

这是 OpenAI 兼容模式，适用于任何实现 Chat Completions 协议的服务。它的关键点是：插件最终会向 /chat/completions 发送请求。

  • 填写服务根路径：https://api.openai.com/v1，插件自动补成 https://api.openai.com/v1/chat/completions。
  • 填写完整接口：https://example.com/v1/chat/completions，插件不会再追加路径。
  • 鉴权 Header：Authorization: Bearer <API Key>。
  • 请求体字段：model、temperature、stream、messages。
Base URL: https://api.openai.com/v1
Actual URL: https://api.openai.com/v1/chat/completions
Header: Authorization: Bearer sk-...

OpenAI Responses

这是 OpenAI Responses 协议模式，适用于官方及兼容 Responses API 的服务。它使用 /responses 端点，请求体结构与 Chat Completions 不同。

  • 填写服务根路径：https://api.openai.com/v1，插件自动请求 /responses。
  • 鉴权 Header：Authorization: Bearer <API Key>。
  • 思考等级映射为 reasoning effort 参数。
Base URL: https://api.openai.com/v1
Actual URL: https://api.openai.com/v1/responses
Header: Authorization: Bearer sk-...

Anthropic

这是 Anthropic 原生模式，适用于 Claude 官方 Messages API。它不走 OpenAI 兼容字段，Header 和请求体结构都按 Anthropic 协议组织。

  • 填写服务根路径：https://api.anthropic.com，插件自动请求 https://api.anthropic.com/v1/messages。
  • 鉴权 Header：x-api-key: <API Key>。
  • 版本 Header：anthropic-version: 2023-06-01。
  • 请求体字段：model、system、messages、temperature、max_tokens、stream。
Base URL: https://api.anthropic.com
Actual URL: https://api.anthropic.com/v1/messages
Header: x-api-key: sk-ant-...

思考等级：每个模型档案可以单独设置思考等级——模型默认、关闭、低、中、高、最高。插件会把等级映射为各家 API 支持的参数：OpenAI reasoning effort、Anthropic thinking budget，以及 Qwen、Zhipu、Moonshot、Doubao、DeepSeek、MiniMax 等厂商开关。如果 Provider 拒绝思考参数，插件会记住并回退。

Smart Echo：当提交面板里已有内容时，打开手动编辑器可以让 LLM 把现有文本解析回 type、scope、subject、body、changes、closes 和 skipCi 等结构化字段。它主要用于“继续编辑已有草稿”，不是重新生成一条完全新的提交信息。

05

截图说明

这里把设置页截图按功能说明放在正文中，便于对照配置项查看。图片均可点击放大。

通用设置

用于控制编辑器字段、提交类型展示、Skip CI 和四个提交动作按钮。团队可以先决定哪些字段需要展示，再把无关项隐藏掉。

提交模板

Velocity 模板定义最终提交信息怎么拼接。支持多模板档案与全局/项目默认，可以把字段顺序、空行、BREAKING CHANGE、issue 引用和 skip ci 放到团队约定的位置。

提交类型

提交类型列表用于约束 type 字段。默认包含 feat、fix、docs、style、refactor、perf、test、build、ci、chore 和 revert，也可以按团队规范增删。

提示词

提示词档案控制 LLM 生成与格式化的行为。可以创建多个档案并在全局与项目维度分别指定默认值，项目提示词优先。

LLM 设置

LLM 设置负责默认模型、接口协议、Base URL、API Key、模型参数、思考等级和 Smart Echo。生成、格式化和解析已有草稿都会读取这里的配置。
